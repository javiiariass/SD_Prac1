ORIGINAL DEL PROFESOR. Comprueba si el texto especificado existe dentro de un campo del libro.

Warning
NO UTILIZAR EN ESTA IMPLEMENTACIÓN. Se mantiene únicamente por motivos de compatibilidad o por si el profesor la usa en el script de comprobación de la práctica. En su lugar, se utiliza comprobar_formateado().

Busca de forma estricta o total ('*') si la sub-cadena Texto aparece en un campo (ISBN, título, autor...). Resulta fundamental para la implementación de búsquedas.

Parameters
[in]LPuntero a estructura TLibro sobre el que se va a buscar.
[in]TextoSub-cadena de la cual se desea comprobar la ocurrencia.
[in]CampoLetra que indica el filtro a aplicar:
  • 'i': ISBN, 't': Título, 'a': Autor, 'p': País, 'd': Idioma, '*': Cualquier campo.
Returns
TRUE si contiene el texto indicado, o FALSE en caso contrario.
See also
comprobar_formateado

Comprueba y formatea coincidencias de búsqueda en un libro.

Dependiendo de Campo, busca Texto en un único campo del libro o en todos los campos si se solicita el comodín '*'. Marca las coincidencias usando códigos ANSI para facilitar su visualización en la consola.

Parameters
[in,out]LLibro que se examina y se puede modificar para resaltar resultados.
[in]TextoTexto de búsqueda a localizar en los campos del libro.
[in]CampoCódigo que indica el campo a buscar: 'i', 't', 'a', 'p', 'd' o '*'.
Returns
TRUE si la búsqueda encontró alguna coincidencia, FALSE si no.

Ejecuta una búsqueda completa en la biblioteca descargando libros.

Itera cada posición de la biblioteca en el servidor, descarga el libro y comprueba si el texto de búsqueda aparece en el campo seleccionado. Muestra todos los resultados coincidentes en pantalla.

Parameters
[in,out]clntHandle del cliente RPC usado para comunicarse con el servidor.
[in]texto_busquedaSubcadena a buscar en los campos del libro.
[in]campo_busquedaIdentificador de campo ('i','t','a','p','d','*').
[in]numero_librosNúmero total de libros existentes en el servidor.
Returns
TRUE si se encontró al menos un libro coincidente, FALSE en caso contrario.
